# Speech to Text

Servicio local de reconocimiento de voz.

| Ruta | Propósito |
|---|---|
| `server.py` | Servidor de transcripción. |
| `test/` | Pruebas y experimentos del servicio. |
| `venv/` | Entorno Python local generado; no debe versionarse. |
| `realtimesst.log` | Log de ejecución; se puede eliminar o rotar. |

Antes de consolidar este módulo debe añadirse un `requirements.txt` reproducible.

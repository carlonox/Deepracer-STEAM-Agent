Linux x86-64. Se prefiere PlatformIO/MicroPython para el ESP32 del proyecto;
esta CLI quedó documentada como respaldo. Verificar integridad con:

```bash
sha256sum tools/arduino/arduino-cli
./tools/arduino/arduino-cli version
```

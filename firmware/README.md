# Firmware

Código de firmware para los microcontroladores del proyecto.

| Componente | Propósito |
|---|---|
| [`esp32-camera-udp/`](esp32-camera-udp/README.md) | Cámara ESP32-S3 que transmite JPEG por UDP. |

Cargar firmware requiere autorización explícita y hardware identificado;
ninguna prueba automática debe hacer upload.

# RAG del aula STEAM

Base de conocimiento para responder preguntas sobre los equipos del aula.

## Contenido

| Ruta | Propósito |
|---|---|
| `Manual_*.md` | Fuentes documentales, un equipo por archivo. |
| `indexador.py` | Construcción o actualización del índice vectorial. |
| `agente.py` | Consulta interactiva de la base de conocimiento. |
| `GUIA_SETUP.md` | Guía operativa incluida como fuente. |
| `requirements.txt` | Dependencias Python. |
| `.env.example` | Plantilla de configuración sin secretos. |

`__pycache__/` y cualquier índice regenerable no son documentación fuente.

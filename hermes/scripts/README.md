# Scripts de Hermes

Herramientas exploratorias y de diagnóstico ejecutables desde el entorno de
Hermes. No forman parte del backend Node ni del navegador ArUco principal.

| Grupo | Archivos |
|---|---|
| Captura | `capture_photo.py` |
| API y login | `debug_api*.py`, `debug_login*.py`, `get_login*.py` |
| Movimiento | `debug_move.py`, `drive_test.py` |
| ROS | `debug_ros*.py`, `explore_ros2.py` |
| Exploración del vehículo | `explore_deepracer*.py` |

Los nombres numerados representan iteraciones de diagnóstico. En una fase
posterior deberían consolidarse en herramientas con argumentos y pruebas.

# Memorias de Hermes

| Archivo | Propósito |
|---|---|
| `MEMORY.md` | Memoria duradera y curada del proyecto. |
| `USER.md` | Preferencias o contexto estable del usuario. |
| `session_*.md` | Resúmenes históricos de sesiones concretas. |

Antes de compartir o versionar una memoria hay que revisar credenciales, datos
personales, direcciones internas y cualquier secreto operativo.

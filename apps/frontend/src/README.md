# Código del frontend

| Ruta | Propósito |
|---|---|
| `main.jsx` | Punto de entrada de React. |
| `App.jsx` | Composición principal y estado de la interfaz. |
| `components/camera/` | Visualización de las cámaras. |
| `components/controls/` | Controles visuales y configuración de gamepad. |
| `components/vr/` | Interfaz de Meta Quest/WebXR. |
| `hooks/` | Lógica reutilizable para vehículo, teclado, gamepad y VR. |
| `services/` | Cliente HTTP del backend. |
| `assets/` | Recursos importados por el código. |
| `index.css` | Estilos globales. |

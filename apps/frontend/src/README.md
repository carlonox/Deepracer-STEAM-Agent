# Código del frontend

| Ruta | Propósito |
|---|---|
| `main.jsx` | Punto de entrada de React. |
| `App.jsx` | Shell de la aplicación y composición de features. |
| `features/vehicle/` | Estado y acciones de modos del vehículo. |
| `components/camera/` | Visualización de las cámaras. |
| `components/controls/` | Controles visuales y configuración de gamepad. |
| `components/dashboard/` | Encabezado y paneles de control por modo. |
| `components/vr/` | Interfaz de Meta Quest/WebXR. |
| `hooks/` | Entradas de teclado, gamepad, conducción VR y WebXR. |
| `shared/` | UI compartida, hooks de estado y utilidades de comandos. |
| `config/` | Resolución centralizada de variables y URLs del frontend. |
| `services/api/` | Cliente HTTP del backend. |
| `styles/dashboard.css` | Estilos del panel de control. |
| `assets/` | Recursos importados por el código. |
| `index.css` | Estilos globales. |

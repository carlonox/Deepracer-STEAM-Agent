# Scripts del backend

Utilidades auxiliares relacionadas con el vehículo.

| Archivo | Propósito |
|---|---|
| `aruco_detect.py` | Detectar marcadores ArUco usando el video del DeepRacer. |

Estos scripts no son endpoints del servidor Node.js; se ejecutan de forma
independiente cuando una tarea de diagnóstico o navegación los requiere.
